Layer 1 · Understanding

The Problem: Naive Bayes Meets Real Numbers

Classic Naive Bayes assumes every feature is binary (word present/absent, pixel on/off) so each feature's class-conditional distribution is a Bernoulli. But most real data — height, temperature, sensor readings, exam scores — is real-valued, living in RD. A Bernoulli can't describe "37.2°C." We need a distribution over continuous space, and the natural default is the Gaussian (Normal) distribution.

🎯 Analogy — Two Archers, Two Targets
Imagine two archers, each shooting arrows at their own target on the same wall. Archer A's arrows cluster tightly around one spot; Archer B's cluster around a different spot, maybe with a different spread. If you find a stray arrow on the wall and don't know who shot it, your best guess is: "which archer's typical cluster is this arrow closer to, accounting for how tightly each archer usually groups their shots?" That's exactly Gaussian Naive Bayes — each class is an archer, each Gaussian is their shot pattern, and classification asks which pattern more plausibly produced the point you're looking at.
Layer 1 → Layer 2

The Generative Model

A generative classifier doesn't directly ask "given X, what is Y?" Instead it models how the data was generated: first a label is drawn, then features are drawn conditioned on that label. Formally, it learns the full joint P(X, Y) by factorizing it into two pieces you estimate separately:

The Generative Factorization
P(X, Y) = P(Y) · P(X | Y)
Eq. 51.1
P(Y) the prior — how common is each class before seeing any features?
P(X|Y) the likelihood — given the class, what does the feature vector look like?

Prior: P(Y)

Modeled as a Bernoulli distribution — same as ordinary Naive Bayes. It only needs one parameter, p, the probability of label 1.

Likelihood: P(X|Y)

Modeled as a multivariate Gaussian — this is the new piece. Each class gets its own bell-shaped cloud in R^D.

Class-Conditional Densities
X | Y=1  ∼  N(μ1, Σ) X | Y=0  ∼  N(μ0, Σ)
Eq. 51.2
μ1, μ0 class-specific means — "where each archer's cluster is centered"
Σ covariance matrix — shape/spread of the cloud (shared across classes here)
📐 Key Simplifying Assumption
Both classes are given the same covariance matrix Σ — only the centers μ₁ and μ₀ differ, not the shape of each cloud. This single assumption is what makes the boundary come out linear, as you'll see below.
Fig 51.1 — Two Gaussian clouds, identical shape (shared Σ), shifted centers (μ₀ vs μ₁)
Layer 2 · Derivation

Estimating Parameters via MLE

We never know the true P(Y), μ₁, μ₀, Σ — we only have training data {(xᵢ, yᵢ)}. Maximum Likelihood Estimation says: pick the parameters that make the observed data most probable. For a Gaussian generative model, this reduces to intuitive "counting and averaging" formulas.

1
Estimate the Prior

The MLE of a Bernoulli parameter is just the sample proportion — the fraction of training points labeled 1.

p̂ = 1/N Σi yi
2
Estimate Each Class Mean

The MLE mean of a Gaussian is the sample average — but computed only over points belonging to that class ("center of mass" of each archer's arrows).

μ̂1 = 1/N₁ Σi: yᵢ=1 xi     μ̂0 = 1/N₀ Σi: yᵢ=0 xi
3
Estimate the Shared Covariance

Since both classes share one Σ, we pool the spread of every point around its own class mean, averaging outer products of the residuals.

Σ̂ = 1/N Σi (xi − μ̂yᵢ)(xi − μ̂yᵢ)T
N₁, N₀ number of training points in class 1 / class 0
μ̂yᵢ the mean of whichever class point xᵢ belongs to
(x−μ)(x−μ)T an outer product — a D×D matrix, not a scalar
Worked Numerical Example — 4 points, 1 feature dimension

Suppose D=1 and we have points: Class 0 → {2, 4}; Class 1 → {8, 10}.

Priors: N=4, N₁=2 → p̂ = 2/4 = 0.5

Means: μ̂₀ = (2+4)/2 = 3,   μ̂₁ = (8+10)/2 = 9

Shared variance (1-D covariance): residuals are (2−3)=−1, (4−3)=1, (8−9)=−1, (10−9)=1. Squared: 1,1,1,1. Average → Σ̂ = 4/4 = 1.

Notice both classes contributed points that are exactly 1 unit from their own mean — so even though the class centers (3 and 9) are far apart, the shared spread is small and tight, which is exactly what "shared Σ" captures.

⚠️ Common Mistake
Don't average the covariance across the whole dataset ignoring class membership without first subtracting each point's own class mean. Subtracting one global mean would inflate Σ̂ with the separation between the classes, which isn't spread — it's signal you want the model to use for classification, not throw away into the covariance.
Layer 3 · Computation

Prediction via Bayes' Rule

With P(Y), μ₁, μ₀, Σ all estimated, classifying a new point Xtest is a direct application of Bayes' Rule: compute the posterior for each class and pick the winner.

Decision Rule
Predict Y=1  if  P(Xtest|Y=1)P(Y=1)  ≥  P(Xtest|Y=0)P(Y=0)
Eq. 51.3
💡 Why No Denominator?
Full Bayes' Rule divides by P(Xtest) to get a true posterior probability. But since that denominator is identical for both classes when comparing them, it cancels out of the comparison entirely — we only need the numerators to decide which class wins.
Layer 2 → Layer 5 · Derivation & Recognition

Decision Boundaries: Linear vs Quadratic

This is the headline result of the lecture. Take logs of both sides of Eq. 51.3, plug in the Gaussian density formula, and simplify. Whether the surviving equation is linear or quadratic in X depends entirely on one assumption: is Σ shared?

Case 1 — Equal Covariance Matrices

1
Take log of both Gaussian densities
log N(x;μ,Σ) = −½(x−μ)TΣ−1(x−μ) + const
2
Expand the quadratic form (x−μ)ᵀΣ⁻¹(x−μ)
xTΣ−1x − 2μTΣ−1x + μTΣ−1μ
3
Subtract the class-1 and class-0 expressions

Because Σ is the same for both classes, the xᵀΣ⁻¹x quadratic term is identical on both sides — it cancels completely.

xTΣ−1x − 2μ₁TΣ−1x + ...  vs  xTΣ−1x − 2μ₀TΣ−1x + ...
4
What remains is linear in x
WTX + b = 0
Linear Decision Boundary
WTX + b = 0 where W ∝ Σ−1(μ1 − μ0)
Eq. 51.4
W a weight vector — direction perpendicular to the separating boundary
b a bias/offset — where the boundary sits along that direction

Case 2 — Different Covariance Matrices

If instead each class gets its own covariance (Σ₁ ≠ Σ₀), the quadratic terms xᵀΣ₁⁻¹x and xᵀΣ₀⁻¹x are no longer identical — they don't cancel. What survives is quadratic in X, giving a curved boundary (an ellipse, parabola, or hyperbola depending on the data).

Quadratic Decision Boundary
XTAX + WTX + b = 0
Eq. 51.5
Fig 51.2 — Same-shape clouds give a flat cut; differently-shaped clouds give a bent one
💡 Intuition
Think of each covariance as defining the "personal space bubble" shape of a class. If both classes have identically-shaped bubbles, only their positions differ — and the fair dividing line between two identically-shaped regions is always straight (a perpendicular bisector, generalized). If one bubble is fat and one is thin, the fair boundary has to bend to respect that asymmetry.

Layer 5 · Recognition

Naming Things Correctly

This equal-vs-different-covariance distinction has standard names you'll see in scikit-learn, textbooks, and exam questions:

SettingBoundaryStandard Name
Binary features, Bernoulli likelihood—(Ordinary) Naive Bayes
Real features, Gaussian, shared ΣLinearGaussian NB (shared Σ) ≈ Linear Discriminant Analysis (LDA)
Real features, Gaussian, separate Σ₁,Σ₀QuadraticQuadratic Discriminant Analysis (QDA)
⚠️ IITM Exam Trap
The word "Naive" in ordinary Naive Bayes refers to the feature-independence assumption. But this lecture's Gaussian model uses a full covariance matrix Σ — it does not assume features are independent (that would force Σ to be diagonal). So "Gaussian Naive Bayes" as taught here is, strictly, the generative model behind LDA, not a features-independent Naive Bayes. If a question asks you to assume independent features too, you must additionally diagonalize Σ — don't silently assume that unless told.
Layer 4 · Reliability

Assumptions, Edge Cases & Failure Modes

Assumption Library

AssumptionConsequence if violated
Data really is Gaussian per classPoor fit if data is skewed, multimodal, or heavy-tailed
Σ shared across classesForces linear boundary; if wrong, underfits true (curved) separation
Enough samples per classΣ̂ becomes unstable / non-invertible with too few points relative to D

Invariant Library

  • Always true: With shared Σ, the boundary is exactly linear.
  • Sometimes true: With different Σ's, the boundary is curved — but can degenerate back to linear/near-linear if Σ₁≈Σ₀.
  • Never true: The boundary is never linear when Σ₁≠Σ₀ in general position (the quadratic term genuinely survives).
⚠️ Failure Visualization
Works: well-separated, roughly elliptical, single-mode classes with enough data. Degrades: classes overlap heavily, or D is large relative to N (covariance estimate gets noisy). Fails: a class is multimodal (e.g. two sub-clusters) — a single Gaussian per class cannot represent two blobs, no matter how you tune Σ.
Layer 6 · Engineering Judgment

When to Reach for This

Use Gaussian NB / LDA when…

  • Features are continuous and roughly bell-shaped per class
  • You want a fast, closed-form, no-iteration classifier
  • You want an interpretable linear decision rule
  • Data is limited — shared Σ means fewer parameters to estimate than QDA

Prefer alternatives when…

  • Classes clearly have different spreads → QDA
  • True decision boundary looks non-quadratic → Logistic Regression / kernel methods
  • Features are genuinely independent given class → true (diagonal-Σ) Naive Bayes is cheaper
  • You don't want to assume any distributional form → discriminative models (next lecture)
Layer 7 · Transfer

Connections & What's Next

Gaussian NB is generative: it models P(X|Y) and P(Y), then derives P(Y|X) via Bayes' Rule. Under the shared-Σ assumption, the resulting decision rule is linear in X — which raises a natural question: what if we skip the generative modeling step entirely and directly model P(Y|X) as a linear function? That's precisely the pivot to discriminative models, starting with Logistic Regression in the next lecture — same linear boundary shape, completely different philosophy of how you got there.

Layer 7 · Retrieval Practice

Test Yourself

Why does assuming a shared covariance matrix force the decision boundary to be linear?
Show answer
Because the quadratic term xᵀΣ⁻¹x is identical for both classes and cancels when you compare (subtract) their log-posteriors — only the linear-in-x terms survive.
What MLE estimate do you use for μ₁, and why only over class-1 points?
Show answer
The sample mean of class-1 points only — because μ₁ is the mean of the Gaussian that specifically generates class-1 data; mixing in class-0 points would bias the estimate toward the wrong center.
If Σ₁ ≠ Σ₀, what shape can the decision boundary take, and what is this model called?
Show answer
A general quadratic curve (ellipse, parabola, or hyperbola) — this setting is called Quadratic Discriminant Analysis (QDA).
Is "Gaussian Naive Bayes" as derived here truly feature-independent, in the sense the word "naive" usually implies?
Show answer
No — it uses a full covariance matrix Σ, so features can be correlated. It's only "naive" in name/lineage; mathematically it's the generative model behind LDA. True feature-independence would require Σ to be diagonal.
Layer 8 · Compression

One-Page Brain

Gaussian Naive Bayes — Everything on One Page

Core idea: model each class as its own Gaussian cloud; classify a point by asking which cloud more plausibly produced it, weighted by how common each class is.

  • Model: P(Y) ~ Bernoulli; X|Y=1 ~ N(μ₁,Σ); X|Y=0 ~ N(μ₀,Σ)
  • MLE: p̂ = fraction labeled 1; μ̂ = class sample mean; Σ̂ = pooled outer-product average of residuals from own-class mean
  • Predict: compare P(X|Y=1)P(Y=1) vs P(X|Y=0)P(Y=0)
  • Shared Σ → linear boundary WᵀX+b=0, W ∝ Σ⁻¹(μ₁−μ₀) — this is LDA
  • Different Σ → quadratic boundary — this is QDA
  • Trap: "naive" here ≠ independent features; Σ is full, not diagonal
  • Next: discriminative twin — Logistic Regression models P(Y|X) directly, no Gaussian assumption needed
