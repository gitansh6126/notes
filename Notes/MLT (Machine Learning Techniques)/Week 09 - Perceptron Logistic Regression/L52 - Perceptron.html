The Perceptron Algorithm

The first discriminative classifier: no probability distributions, no Bayes' Rule — just a hyperplane, a mistake, and a nudge. If it's wrong, push the boundary toward the point that fooled it.

Layer 1 · Understanding

Generative vs. Discriminative — A Second Look

Lecture 51's Gaussian Naive Bayes was generative: it modeled how the data came to exist — draw a label, then draw features from that label's distribution — and used Bayes' Rule to flip that into a classifier. The Perceptron takes the opposite philosophy.

GenerativeDiscriminative
Models P(X|Y) and P(Y), derives P(Y|X) via BayesModels P(Y|X) — or even just a hard decision rule — directly
Cares how features are distributed per classDoesn't care about feature distribution at all
Can generate synthetic samplesCan only classify, never generate
Example: Gaussian NB / LDAExample: Perceptron, Logistic Regression
🎯 Analogy — Profiler vs. Bouncer
A generative model is like a criminal profiler: it studies everything about how each type of person typically behaves, builds a full mental model of each group, and uses that rich understanding to judge a new case. A discriminative model is like a bouncer at a club door: he doesn't care about your life story or where you grew up — he just needs a fast rule ("if you look like this, you're in; if you look like that, you're out") that draws the line correctly. The Perceptron is the bouncer: it only ever asks "which side of my line are you on?"
Layer 1 → Layer 2

The Linear Separability Assumption

The Perceptron commits to a strong, deterministic goal: model P(Y=1|X) as either exactly 1 or exactly 0 — never "maybe." It does this with a single hyperplane test.

Deterministic Decision Rule
P(Y=1|X) = 1  if  WTX ≥ 0 P(Y=1|X) = 0  otherwise
Eq. 52.1
W the weight vector — its direction defines a hyperplane through the origin
WTX a signed distance-like score — sign tells you which side of the hyperplane X lands on
Fig 52.1 — A separating hyperplane; W points toward the Y=1 half-space
⚠️ Limitation
This only works if the data is linearly separable — some hyperplane perfectly divides the two classes. A single outlier or overlapping classes means no W exists that gets everything right, and the algorithm you're about to see will never stop searching.
Layer 3 · Computation

The Perceptron Algorithm

🕰️ History
Developed by Frank Rosenblatt in the 1950s — one of the earliest trainable models in machine learning, decades before "deep learning." Its update rule is disarmingly simple, yet it's the direct ancestor of the modern neuron/gradient-update idea.

The Perceptron doesn't compute anything in closed form (no MLE, no matrix inverse). It iterates: look at one point at a time, and only act when it's wrong.

1
Initialize
W₀ = 0
2
Pick a training point

Select some (xᵢ, yᵢ) from the dataset (cycle through them, or pick at random).

3
Check the current prediction
sign(WtTxi) =? yi
4
Correct → do nothing. Wrong → update.
Wt+1 = Wt + xi·yi
5
Repeat until every point is classified correctly

If the data is linearly separable, this is guaranteed to happen in a finite number of steps (Perceptron Convergence Theorem).

The Update Rule
Wt+1 = Wt + xi·yi
Eq. 52.2
yi the true label, ∈ {+1, −1}
xi·yi the feature vector, flipped in direction if the true label is −1
Layer 2 · Derivation / Intuition

Why Adding x·y Actually Fixes the Mistake

This isn't an arbitrary rule — it's the smallest nudge that moves the score for the misclassified point in the right direction. Check what happens to the score on that same point right after the update:

1
New score on the mistaken point
Wt+1Txi = (Wt + xiyi)Txi
2
Expand
= WtTxi + yi·(xiTxi)
3
Since xᵢᵀxᵢ = ‖xᵢ‖² ≥ 0 always

The new score moves by yᵢ·‖xᵢ‖² — a shift in the same sign as yᵢ. If yᵢ=+1, the score increases (pushed toward positive); if yᵢ=−1, the score decreases (pushed toward negative). Either way, the update moves the score toward the correct side for that exact point.

💡 Geometric Picture
Adding yᵢxᵢ to W rotates the weight vector — and therefore the hyperplane perpendicular to it — toward the misclassified point when yᵢ=+1 (pulling the "accept" region to include it), or away from it when yᵢ=−1 (pushing the "accept" region to exclude it). One mistake, one small rotation.
Worked Numerical Example — 2D, three updates

Data: x₁=(2,1), y₁=+1; x₂=(−1,1), y₂=−1. Start W₀=(0,0).

Step 1: check x₁: W₀ᵀx₁ = 0, sign is ambiguous/0 → treat as wrong for y=+1. Update: W₁ = (0,0) + 1·(2,1) = (2,1).

Step 2: check x₂: W₁ᵀx₂ = 2(−1)+1(1) = −1. sign(−1) = −1 = y₂ ✓ correct, no update.

Step 3: recheck x₁: W₁ᵀx₁ = 2(2)+1(1) = 5 ≥ 0 ✓ correct, no update. Both points now correctly classified — converged after a single update.

Layer 4 · Reliability

Convergence, Assumptions & Failure Modes

Assumption Library

AssumptionConsequence if violated
Data is linearly separableAlgorithm never terminates — loops forever correcting the same points
Hyperplane passes through the origin (no explicit bias)Cannot represent boundaries offset from origin, unless features are augmented with a constant 1 dimension
Finite dataset, finite margin between classesNeeded for the convergence bound (more margin → fewer updates needed)

Invariant Library

  • Always true: if separable, the algorithm halts in a finite number of updates (Perceptron Convergence Theorem).
  • Sometimes true: the found W is a separating hyperplane — not necessarily the "best" one (no notion of margin maximization).
  • Never true: guaranteed convergence when classes overlap or are not linearly separable.
⚠️ IITM Exam Trap
The Perceptron finds some separating hyperplane, not the best one — there's no guarantee it maximizes the margin between classes. Multiple runs (different point order, different initialization) can converge to different valid boundaries. Don't confuse this with SVM, which is explicitly designed to find the maximum-margin hyperplane.
Layer 6 · Engineering Judgment

When to Reach for This

Use the Perceptron when…

  • You know (or strongly believe) data is linearly separable
  • You want the simplest possible online/streaming learner
  • You're teaching/learning the building block behind neural network units

Prefer alternatives when…

  • Data is noisy / not perfectly separable → Logistic Regression (soft probabilities, no infinite loop)
  • You want the widest-margin, most robust boundary → SVM
  • You need calibrated probability outputs → Logistic Regression
Layer 7 · Transfer

Connections & What's Next

The Perceptron proves that a purely discriminative, non-probabilistic algorithm can learn a linear boundary just by correcting mistakes — no distributional assumptions like L51's Gaussian at all. But it has two visible gaps: it gives a hard 0/1 decision with no notion of confidence, and it has no preference among the (possibly many) hyperplanes that separate the data. The next lecture, Logistic Regression, fixes the first gap by replacing the hard sign() with a smooth probability curve; SVMs later fix the second by explicitly maximizing the margin.

Layer 7 · Retrieval Practice

Test Yourself

Why does the Perceptron update W by adding xᵢ·yᵢ specifically, rather than some other vector?
Show answer
Because it's the minimal correction that provably shifts the score W^Tx_i on the mistaken point in the correct direction — the shift equals yᵢ‖xᵢ‖², which has the same sign as yᵢ.
What happens if you run the Perceptron on data that isn't linearly separable?
Show answer
It never converges — it keeps finding mistakes and updating forever, since no W exists that classifies every point correctly.
Does the Perceptron find the "best" separating hyperplane?
Show answer
No — it finds any hyperplane that separates the data with zero training error, with no guarantee of maximizing the margin. That refinement is what SVM adds later.
Layer 8 · Compression

One-Page Brain

Perceptron Algorithm — Everything on One Page

Core idea: discriminative, mistake-driven learning — start with W=0, and every time a point is misclassified, nudge W by adding that point's feature vector scaled by its true label.

  • Decision rule: predict Y=1 iff WᵀX ≥ 0 (deterministic, no probabilities)
  • Requires: linear separability — some hyperplane must perfectly split the classes
  • Update: W ← W + xᵢyᵢ, only on mistakes
  • Why it works: the update always shifts the mistaken point's score by yᵢ‖xᵢ‖² — toward the correct sign
  • Convergence: guaranteed in finite steps if separable; loops forever if not
  • Limitation: finds a separator, not the max-margin one; no confidence scores
  • Next: Logistic Regression (soft probabilities) → SVM (max-margin)
