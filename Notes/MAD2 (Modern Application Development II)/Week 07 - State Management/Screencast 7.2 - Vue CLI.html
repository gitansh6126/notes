Single File Components
in Vue CLI

HTML, JavaScript, and CSS, all living in one .vue file — instead of three files pretending to be one component.

Greeting.vue
template — HTML 
<template>
  <div class="greeting">{{ msg }}</div>
</template>
script — JavaScript 
<script>
export default {
  data() { return { msg: 'Hello Vue!' } }
}
</script>
style — CSS (scoped) 
<style scoped>
.greeting { color: teal; }
</style>
one file, three languages, one component
00

Overview

Single File Components package a component's markup, logic, and styling into one .vue file. The Vue CLI, built on Node.js and npm, is the toolchain that turns these files into a running development server — and later, into a production-ready build.

01

Why scoped Matters

Without it, a class name in one component can quietly restyle another.

Unscoped style

.title { color: red; } — Header.vue
.title — Footer.vue (turns red too)

The rule leaks globally and silently restyles any element sharing that class name, anywhere in the app.

Scoped style

.title { color: red; } — Header.vue
.title — Footer.vue (unaffected)

Vue attaches a unique data attribute to this component's markup, so the rule only ever matches here.

02

The Vue CLI Workflow

Two commands cover most of the day-to-day.

CommandWhat it doesUse it for
vue serve file.vue Launches a local dev server for a single .vue file — no full project setup needed. rapid prototyping
vue build file.vue Compiles the SFC into browser-ready static HTML, JS, and CSS in a dist/ folder. production deployment
03

The Foundation: Node.js & npm

Node.js

A runtime that executes JavaScript outside the browser — the engine the Vue CLI's build system runs on.

npm

Installs the Vue CLI and its dependencies. Plays the same role pip plays in the Python ecosystem.

-g flag

Installs a package globally, so its command-line tool is available system-wide, not just in one project.

04

Workflow Summary

Setup
node -v
Installation
npm install -g @vue/cli
Prototyping
vue serve file.vue
Production
vue build → dist/
05

Important Considerations

◆

Not mandatory for every project. Small or simple apps can still work perfectly well with plain HTML, CSS, and JavaScript — SFCs and the CLI earn their complexity on larger builds.

◆

Learning Node.js pays off beyond the basics — it unlocks plugins, CSS pre-compilation, and advanced deployment paths like building the app as a PWA.

06

Key Takeaways

One file, one component

Template, script, and style together keep a component's logic and presentation modular and easy to find.

Scope your styles

The scoped attribute is a small habit that prevents a whole category of hard-to-trace CSS bugs.

Right-size the tooling

Vue CLI is powerful, but plain HTML/CSS/JS is still the right call for small, simple projects.
