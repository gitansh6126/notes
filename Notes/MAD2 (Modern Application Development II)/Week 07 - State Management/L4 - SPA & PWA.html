00

From Full Reloads to Native-Like

Traditional apps re-fetched an entire HTML page from the server for every click or form submission — a round trip that made the experience feel slow. Modern architectures push navigation and data handling to the client, chasing a smoother, more native feel.

01

Single Page Applications

An SPA updates the current page by fetching only what changed — never the whole document.

Smooth UX

Transitions happen in place, without the blank-page flash of a reload.

Async fetching

Data arrives via AJAX / the Fetch API, independent of full-page navigation.

JS-based routing

JavaScript manages history and state instead of the server.

Three ways developers have built this over time:

simplest

CSS-only

Toggle visibility with display classes. Easy, but limited interactivity.

historical

Browser Plugins

Java Applets, Flash. Heavy performance overhead — mostly abandoned.

modern

Frameworks

Vue, React, Angular — manage components and state directly.

SEO

Search crawlers don't always execute JavaScript, which can make SPA content harder to discover.

Analytics

Traditional page-load analytics miss component-level state changes that never trigger a "new page."

02

Where Does the Work Happen?

SPAs can still be built on very different server architectures.

ArchitectureWho does the workThink of it as…
Thin Server Server is just an API. The browser handles logic, navigation, and rendering. server hands you ingredients, you cook
Thick Stateful Server holds the full system + client state, computes updates, pushes them in-place. Still an SPA. a chef who remembers your usual order
Thick Stateless Server does the heavy computing but keeps no memory — the client resends its current state every request. a chef with amnesia; you repeat your order each time

Progressive Web Apps

PWAs close the gap to native — offline access, installability, and system integration, on top of a normal SPA.

Web Workers

Background scripts that proxy network requests and serve cached content when offline.

Web Manifest

A JSON file describing the app so the OS can identify and install it.

Installation

Runs windowed, without browser chrome — no URL bar, no tabs.

WebAssembly

A compiled format enabling near-native speed for compute-heavy tasks in the browser.

05

Key Takeaways

Fetch less, feel faster

SPAs trade full-page reloads for targeted async updates — that's most of the perceived speed gain.

Offline is a worker's job

PWAs get offline access by proxying requests through a web worker that can serve from cache.

A spectrum, not a switch

Web vs. native isn't binary — thin/thick server choices and PWA features let web apps creep steadily closer to native.
